## 搬瓦工 KiwiVM 是什么

KiwiVM Control Panel 是搬瓦工（BandwagonHost）自主研发的 VPS 后台管理面板。每一台搬瓦工 VPS 都配有独立的 KiwiVM 实例，用于管理这台机器的全部日常操作。

简单说：KiwiVM 就是你的 VPS 遥控器。开机关机、重装系统、换机房、重置密码、查流量——全在这里。

不同于市面上大多数 VPS 厂商使用的商业 SolusVM 面板，KiwiVM 是搬瓦工自己造的轮子，功能设计上更贴合实际使用需求，自动化程度也更高。

## KiwiVM 功能详解

KiwiVM 的功能分三个板块：Admin functions（管理功能）、Migration（迁移）、KiwiVM Extras（扩展功能）。下面按实际使用频率来讲。

### 主界面（Main Controls）

打开 KiwiVM 默认就在这里。能看到：

- 机房代号和节点 ID
- VPS 的 IP 地址和 SSH 端口
- 当前运行状态（开机/关机）
- 内存、硬盘、月流量的实时使用情况

这里还有开机、关机、重启按钮，以及挂载 ISO 的选项（给进阶用户用的）。

### 重装系统（Install new OS）

用得最多的功能之一。选好操作系统，点一下，几分钟就完成重装。搬瓦工支持 20 多个 OS 模板，Debian、Ubuntu、CentOS 这些主流系统都有，32 位和 64 位版本都提供。2026 年还新加了 Debian 13 的支持。

步骤：

1. 在左侧菜单点 **Install new OS**
2. 下拉菜单选择系统版本
3. 勾选确认，点击重装
4. 等待完成后，新的 root 密码会显示在页面上

**注意保存新密码**，或者马上去重置 root 密码，否则关掉页面就找不回来了。

### 迁移机房（Migrate to another DC）

这是搬瓦工区别于大多数 VPS 商家的一个特色功能。支持迁移的套餐，可以在多个机房之间自由切换，不限次数，不额外收费。

操作路径：左侧菜单 → **Migrate to another DC** → 选目标机房 → 确认迁移。

迁移过程中 VPS 会有短暂停机（一般几分钟），迁移完成后 IP 地址会改变，需要重新配置 SSH 连接信息。

CN2 GIA-E 套餐可以切换的机房最多，包括洛杉矶 DC6/DC9、日本软银、荷兰 EUNL\_9、加拿大温哥华、新加坡等，最多可选 12 个以上机房。

### 重置 Root 密码（Root password modification）

忘记 SSH 密码了？不用慌。

1. 左侧菜单点 **Root password modification**
2. 点 **Generate and new root password**
3. 新密码立刻显示在页面上

这个操作会立即生效，不需要重启 VPS。拿到新密码之后直接用 SSH 工具重新连接就行。

### 快照与备份（Snapshots & Backups）

两个功能分开讲：

**快照（Snapshots）**：手动触发，保存 VPS 当前的完整状态。建议在每次重大操作前创建一个快照，出问题随时回滚。支持创建一个永久快照（Sticky），不会自动过期。这个功能在其他 VPS 商家通常要收费，搬瓦工是免费的。

**备份（Backups）**：系统自动定期执行，不需要手动操作。备份数据可以导入到快照然后恢复到 VPS 中。

### 换 IP

有两种方式。一是通过迁移机房顺带换掉 IP，二是在 SLA 套餐里每两周可以免费主动换一次 IP。普通 CN2 GT 和 CN2 GIA-E 套餐没有主动换 IP 的免费额度，但迁移机房之后 IP 会自动变更。

### Root Shell（在线 SSH 终端）

KiwiVM 提供三种在线 Shell：

- **Basic**：基础 Shell，功能有限
- **Advanced**：高级 Shell，适合日常命令操作
- **Interactive**：VNC 形式的交互终端，可以处理无法正常 SSH 连接的情况

通常用 Termius、Xshell、PuTTY 这类客户端连接 SSH 速度更快，在线 Shell 主要是备用方案。

### 两步验证（Two-factor authentication）

给 KiwiVM 登录加一层保险。开启后，每次直接访问 KiwiVM 面板（非从官网后台跳转）时，需要额外输入 Google Authenticator 或 Authy 生成的验证码。账号安全敏感的用户建议开启。

### API 接口

KiwiVM 提供完整的 API，可以用 Python、PHP、Shell 等编程语言调用，实现自动化管理操作：查看 VPS 状态、重启、获取流量数据等。API Key 在左侧菜单的 **API** 选项下查看。

不要把 API Key 透露给不信任的人。

### 审计日志（Audit Log）

记录 KiwiVM 后台的全部操作历史，包括登录记录、开关机、重装系统、API 调用等。怀疑账号有异常登录时可以来这里查。

### 私有网络（Private Network）

部分套餐支持添加私有 IP，在同一机房内的两台 VPS 之间建立内网连接。内网传输数据不计入公网流量，适合有多台服务器、需要内部通信的用户。
